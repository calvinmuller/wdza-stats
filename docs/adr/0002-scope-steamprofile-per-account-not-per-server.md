# Scope SteamProfile per Steam account, not per Server

WARDOGS players' Steam Web API data (persona name, avatar, achievements) is global to their Steam account — identical regardless of which WARDOGS server they played on — whereas PlayerCareerStat is deliberately scoped to `(serverId, steamId)`, since career totals shouldn't blend across communities. We decided to store SteamProfile keyed by `steamId` alone, in its own table, joined into per-Server views rather than duplicated per Server. The rejected alternative — denormalizing avatar/persona name/achievements onto `playerCareerStats` the way `displayName` already is — would mean re-fetching and storing identical Steam data once per Server for any player tracked on more than one, and would make it easy to misread a global achievement badge as a WDZA-specific stat.
